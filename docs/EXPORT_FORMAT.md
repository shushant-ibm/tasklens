# TaskLens Export Bundle Specification (`.tasklens`)

The `.tasklens` file format is a standard ZIP archive containing human-readable JSON files and a self-contained offline HTML visualizer.

---

## 1. Archive File Structure

```
tasklens_export_<timestamp>.tasklens (ZIP Archive)
│
├── manifest.json         # High-level metadata, SDK version, OS specs
├── tasks.json            # Array of ScheduledWork entities
├── events.jsonl          # JSON Lines streaming event log
├── attempts.json         # Array of ExecutionAttempt records
├── diagnoses.json        # Array of Diagnosis objects with evidence
├── environment.json      # System environment snapshots (battery, network, doze)
└── README.html           # Standalone, offline, interactive HTML report
```

---

## 2. File Specifications

### `manifest.json`
Contains bundle identification, export timestamp, generator version, and device telemetry:
```json
{
  "exportId": "a93e3d2a-89a1-43ef-92e1-4c126fa289e2",
  "generatedAt": "2026-09-19T22:30:00Z",
  "sdkVersion": "0.1.0",
  "platform": "Android",
  "osVersion": "15 (API 35)",
  "deviceModel": "Pixel 7 Pro",
  "appVersion": "1.0.0",
  "totalTasks": 12,
  "totalEvents": 487
}
```

### `events.jsonl`
Each line is a valid JSON object matching `TaskLensEvent`. This format allows efficient streaming ingestion and line-by-line parsing:
```json
{"id":"e-1","taskId":"sync-work","timestamp":"2026-09-19T22:00:01Z","type":"TASK_STARTED","source":"WORK_MANAGER","severity":"INFO","attributes":{"worker_class":"SyncWorker"}}
{"id":"e-2","taskId":"sync-work","timestamp":"2026-09-19T22:00:05Z","type":"BATTERY_CHANGED","source":"SYSTEM_BROADCAST","severity":"WARNING","attributes":{"battery_saver":"true"}}
```

### `README.html`
A completely standalone HTML report generated by `HtmlReportGenerator`. It features:
- Responsive CSS styling for desktop and mobile viewports.
- Pure CSS tabs for switching between Tasks, Timeline, Diagnoses, and Environment.
- Timeline visualization showing events in chronological sequence.
- Evidence breakdown linking each diagnosis directly to source events.
- Zero external script or stylesheet tags (functions completely offline in air-gapped environments).
